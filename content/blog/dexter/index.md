# Dexter: AI 기반 자율 금융 리서치 에이전트 분석

> **GitHub**: [virattt/dexter](https://github.com/virattt/dexter)

---

## 🔍 개요

**Dexter**는 `virattt`이 개발한 오픈소스 자율 금융 리서치 에이전트다.
복잡한 금융 질문을 단계별 실행 계획으로 분해하고, 실시간 시장 데이터를 수집한 뒤,
**자체 검증(Self-Validation)** 을 통해 신뢰 가능한 분석 결과를 도출한다.

개발자 본인은 이를 "**금융 리서치를 위한 Claude Code**"라고 표현했다.

---

## 🚨 해결하려는 문제

기존 AI 에이전트의 가장 큰 문제는 **출력 결과를 스스로 검증하지 않는다는 것**이다.
금융 도메인에서는 이게 단순한 불편함이 아닌 위험이 된다.

| 기존 에이전트의 한계 | Dexter의 접근 |
|---|---|
| 잘못된 데이터를 확신 있게 반환 | 검증 에이전트가 결과를 재확인 |
| 기간이 맞지 않는 데이터 혼용 | 시간 축 일관성 자동 체크 |
| 금융 지표 오해석 | 도메인 특화 논리 검증 |
| 무한 루프로 API 낭비 | Loop Detection + Step Limit 적용 |

---

## 🏗️ 아키텍처: 멀티 에이전트 구조

Dexter는 단일 LLM 호출이 아닌, **역할이 분리된 4개의 전문 에이전트**로 구성된다.

```
사용자 질문
    │
    ▼
┌─────────────────┐
│  Planning Agent  │  ← 복잡한 쿼리를 실행 가능한 세부 태스크로 분해
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  Action Agent   │  ← Financial Datasets API로 실시간 데이터 수집
└────────┬────────┘
         │
         ▼
┌──────────────────┐
│ Validation Agent │  ← 데이터 정확성, 일관성, 논리 오류 검증
└────────┬─────────┘
         │
         ▼
┌─────────────────┐
│  Answer Agent   │  ← 검증된 결과를 최종 리서치 리포트로 합성
└─────────────────┘
```

### 핵심 혁신 포인트

- **자체 검증 루프**: 검증 에이전트가 통과시켜야만 최종 답변 생성
- **안전장치(Safety Layer)**: 무한 루프 감지 + 단계 수 제한으로 API 비용 방어
- **스크래치패드 로깅**: `.dexter/scratchpad/`에 모든 툴 콜을 JSONL로 저장해 디버깅 지원

## ⚙️ 기술 스택

| 구성요소 | 기술 |
|---|---|
| 런타임 | **Bun** (Node.js 대비 빠른 실행 속도) |
| 에이전트 오케스트레이션 | **LangChain.js** |
| LLM | OpenAI / Anthropic / Ollama (선택 가능) |
| 데이터 소스 | Financial Datasets API, Yahoo Finance |
| 터미널 UI | **React + Ink** |
| 평가 추적 | **LangSmith** (LLM-as-judge 방식) |

## 🚀 빠른 시작

```bash
# 레포지토리 클론
git clone https://github.com/virattt/dexter.git
cd dexter

# 의존성 설치 (Bun 런타임 필요)
bun install

# 환경 변수 설정
cp .env.example .env
# .env 파일에 아래 키 추가
# OPENAI_API_KEY=your_key_here
# FINANCIAL_DATASETS_API_KEY=your_key_here

# 실행
bun run start
```

WhatsApp 게이트웨이 연동도 지원해서, 본인에게 메시지를 보내는 것만으로 Dexter에 쿼리를 날릴 수 있다.

## 💡 실제 사용 예시

**"이 주식이 저평가되어 있는가?"** 라는 질문을 입력하면 Dexter는 다음과 같이 처리한다.

```
1. 현재 주가 수집
2. 과거 P/E 비율 수집
3. 업종 평균 P/E 수집
4. 밸류에이션 지표 계산
5. 데이터 일관성 검증  ← Validation Agent
   - 기간이 일치하는가?
   - 수치들이 논리적으로 타당한가?
   - 사과와 사과를 비교하고 있는가?
6. 최종 리서치 리포트 합성  ← Answer Agent
```

## 📊 경쟁 도구와의 비교

| 도구 | 특징 | 한계 |
|---|---|---|
| **Dexter** | 금융 특화, 자체 검증 | 금융 외 도메인 부적합 |
| **AutoGPT** | 범용 자동화 | 도메인 검증 레이어 없음 |
| **CrewAI** | 멀티 에이전트 워크플로우 | 금융 특화 로직 없음 |
| **LangChain** | 유연한 LLM 체인 | 자율성 없음 |

> **결론**: 실시간 데이터 집계 + 멀티스텝 추론 + 검증이 모두 필요한 금융 리서치에는 Dexter가 최적.

## 🔑 금융권 취업과의 연결고리

Dexter가 주목받는 이유는 단순히 "AI 챗봇"을 넘어서기 때문이다.
금융권에서 실제로 요구하는 역량과의 연결을 생각해보면:

- **데이터 파이프라인 설계**: Planning → Action → Validation → Answer 흐름은 금융 데이터 ETL 파이프라인 사고방식과 유사
- **리스크 관리 감각**: 자체 검증과 안전장치 설계는 금융 시스템의 오류 내성(Fault Tolerance) 개념과 맞닿아 있음
- **AI/LLM 금융 적용 능력**: FinTech·디지털 금융 직군에서 점점 중요해지는 역량
